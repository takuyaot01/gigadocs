## このリポジトリについて

教育機関向けの Microsoft 365・Windows・Azure AD・Intune の日本語スライドを保管しています。教育プラットフォームの概要、端末の展開・更新・管理、ユーザー管理などの資料を **PDF 形式**でダウンロードできます。

> 資料は 2020 年 8～9 月時点の製品名・機能・画面に基づいています。Azure AD など当時の名称を含み、現在の仕様とは異なる場合があります。最新情報は [Microsoft Learn](https://learn.microsoft.com/ja-jp/) をご確認ください。
